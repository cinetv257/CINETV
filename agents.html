Le scanner

Scannez. Vérifiez. Laissez entrer.

À l'entrée de l'événement, l'agent scanne le QR code présenté par le participant. L'application vérifie le billet en temps réel.

  • Lecture instantanée du QR code
  • Vérification automatique du billet
  • Décision immédiate : accès ou refus
Validation

Les statuts d'un billet.

Chaque scan affiche un statut clair : couleur, icône et texte.

Billet valide

Accès autorisé

Le billet est authentique et n'a pas encore été utilisé.

Déjà utilisé

Accès refusé

Ce billet a déjà été scanné précédemment.

Invalide

Accès refusé

Le billet n'est pas reconnu par le système bTicket.

À vérifier

Contrôle manuel

Une vérification supplémentaire est demandée à l'agent.

En 3 étapes

Le parcours d'une validation.

Chaque billet passe par les mêmes étapes, dans un ordre clair et rapide, même en pleine affluence.

  • 01

    Le participant présente son billet

    Il affiche le QR code de son billet depuis son application bTicket.

  • 02

    L'agent scanne le QR code

    Le scanner de bTicket lit le code en un instant, même en faible luminosité.

  • 03

    Le système décide

    L'accès est accordé ou refusé selon le statut du billet.
